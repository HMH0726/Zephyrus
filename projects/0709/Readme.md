# XIAO nRF52840 Plus 商用級多頻道藍牙滑鼠韌體專案

這是一套基於 Zephyr OS 的純血可攜式開發環境，專為 XIAO nRF52840 Plus 開發板設計。本專案旨在將開發板轉化為具備「一機多頻道、無縫秒連切換」的高階商用藍牙滑鼠核心，並從作業系統底層突破了傳統藍牙協議的配對限制。

## 🖱️ 設備核心功能

燒錄本韌體後，設備將具備媲美高階商用滑鼠（如 Logitech 旗艦系列）的連線與管理能力：

1. **標準藍牙 HID 裝置**
   設備對外廣播為標準藍牙滑鼠，相容於 Windows、macOS、Linux、iOS 與 Android 等所有主流具備藍牙功能的平台，無須安裝額外驅動。

2. **三頻道獨立記憶與無縫切換 (CH1 / CH2 / CH3)**
   設備可同時記憶 3 台不同主機的連線金鑰。透過按下實體按鍵 **(D3)**，即可在中斷當前連線後，瞬間切換至下一個頻道並發送廣播，實現多設備間的無縫秒連。

3. **突破限制：支援雙系統與同設備多頻道綁定**
   傳統藍牙設備在面對電腦雙系統（如 Windows + Ubuntu），或試圖在同一支手機上綁定兩個不同頻道時，會觸發藍牙 SMP 安全協議的防護（報錯 0x12），強迫使用者必須先「忘記裝置」才能重新配對。
   本韌體透過客製化補丁，破解了 Zephyr 底層的 `bt_id_find_conflict` 限制，允許同一台主機（相同的 IRK 身分金鑰）自由綁定在不同的頻道上，徹底解決雙系統工作者的痛點。

4. **硬體級一鍵重置 (物理核彈抹除)**
   透過按下實體按鍵 **(D6)**，系統將強制觸發底層 NVS (非揮發性記憶體) 的抹除機制，將藍牙配對磁區全數填入 0xFF 並自動重啟。適用於配對錯亂、轉交設備或全面重新綁定時的安全重置。

## 🛠️ 開發環境與架構說明

本專案採用「純血可攜式 (Portable)」架構，所有工具鏈（Python, CMake, Ninja, Zephyr SDK）皆掛載於隨身碟或特定目錄下，不污染開發者的作業系統環境。

針對跨作業系統（Windows / Linux）複製貼上時常見的換行符號 (CRLF/LF) 與縮排 (Space/Tab) 導致的 Git 補丁損毀問題，本專案採用 Python 位元組級別 (Byte-level) 腳本自動生成絕對完美的 Diff 檔案，確保環境 100% 穩定。

### 目錄結構
- `啟動環境.bat`：用於掛載免安裝工具鏈的啟動腳本。
- `0709/make_patch.py`：核心補丁生成腳本，負責鎖定 UNIX 換行格式與精準的 Diff 行數計算。
- `0709/dual_boot_fix.patch`：由腳本生成的標準 Git 補丁檔，用於破解藍牙配對限制（請勿手動修改此檔）。

## 🚀 快速啟動與編譯指南

### 1. 啟動開發環境
雙擊執行專案根目錄下的 `.bat` 啟動腳本。
終端機開啟後，腳本會自動掛載環境變數，並安靜地將雙系統配對補丁 (`dual_boot_fix.patch`) 套用至 Zephyr 核心記憶體中。
